# NU40DK ISS 트래커

국제우주정거장(ISS)·톈궁·스타링크가 지금 어디 있는지, 언제 내 머리 위로 지나가는지 원형 화면(GC9A01 240×240)에 띄웁니다.
NU40DK(nRF52840)는 와이파이가 없어서 맥의 파이썬이 데이터를 받아 USB 시리얼로 보내고, 보드는 그 사이를 원궤도로 이어서 계산해 그립니다.

## 화면 (자동으로 넘어감)

| 순서 | 화면 | 내용 |
|---|---|---|
| 1 | ISS 궤도 | ISS를 가운데 둔 지구. 낮·밤, 밤쪽 도시 불빛, 지나온 길(파랑)·갈 길(주황), 내 위치 |
| 2 | 원격측정 | 속도(1초에 몇 km), 높이, 한 바퀴 시간, 위경도, 내 위치에서 거리, 햇빛/지구 그림자 |
| 3 | 다음 통과 | ISS·톈궁 중 먼저 오는 쪽이 내 하늘을 지나갈 길과 남은 시간. 지나가는 동안엔 이 화면에 고정 |
| 4 | 톈궁 | 중국 우주정거장 궤도 (빨강·금색) |
| 5 | 스타링크 군단 | 내 위치를 가운데 둔 지구 둘레의 스타링크. 가장 최근 발사분은 분홍 |
| 6 | 서울 하늘 스타링크 | 지금 내 지평선 위에 떠 있는 스타링크 |
| 7 | 탑승자 | 지금 우주에 있는 사람과 소속 기관 |

## 데이터 (모두 키 없음)

| 무엇 | 어디서 | 얼마나 자주 |
|---|---|---|
| ISS 위치·속도 | [wheretheiss.at](https://wheretheiss.at/w/developer) | 5초 |
| ISS·톈궁·스타링크 궤도값(TLE) | [CelesTrak](https://celestrak.org) | 하루 1번 (스타링크 묶음은 3시간, 연달아 받으면 403) |
| 통과 계산 | [skyfield](https://rhodesmill.org/skyfield/) (맥에서) | 1분 |
| 탑승자 | [Launch Library 2](https://thespacedevs.com/llapi) | 1시간 (무료 한도 시간당 15회라 파일 캐시) |

open-notify의 탑승자 API는 2024년 명단에서 멈춰 있어서 쓰지 않습니다.

## 배선 (GC9A01)

| 화면 | NU40DK |
|---|---|
| VCC / GND | 3V3 / GND |
| SCL / SDA | 47 / 45 |
| CS / DC / RES / BLK | 44 / 43 / 42 / 41 |

## 실행

```bash
pip3 install pyserial skyfield
./build.sh upload          # 리셋 버튼 빠르게 두 번 → 굽기 드라이브가 뜨면 자동 복사
python3 host/iss.py        # 맥에서 데이터 보내기 (--screen 0~6 으로 화면 고정)
```

내 위치는 `host/.env`에 `LAT=`, `LON=`으로 적습니다(깃에 안 올라감). 없으면 서울 강남구 일대입니다.

## 만들면서 알게 된 것

- **이 보드의 `sscanf`는 소수(`%f`)를 못 읽습니다.** 0을 돌려줘서 데이터가 안 들어간 것처럼 보입니다. `strtod`로 직접 읽습니다.
- **loop 스택은 4KB입니다.** 1.4KB 배열을 지역 변수로 두면 보드가 조용히 죽고 USB도 사라집니다. 큰 배열은 `static`으로 둡니다.
- **한글 글꼴**: `tools/kofont.py`가 펌웨어에 쓰인 한글만 골라 GFX 글꼴(`ko_font.h`)로 만듭니다. 2배 크기로 만들어 0.5배로 그리면 2×2 샘플링이 그대로 안티에일리어싱이 됩니다. 문구를 바꾸면 다시 돌리세요.
- **스타링크**: 1만 개를 다 넣으면 느리고 메모리가 빠듯해서 4,500개만 보냅니다(최근 발사분은 전부). 하늘 위 개수는 실제 전체 수에 맞춰 늘려서 보여줍니다.
- 위성 위치는 원궤도 근사라 맥 연결이 끊긴 채 오래 두면 실제와 점점 벌어집니다.
